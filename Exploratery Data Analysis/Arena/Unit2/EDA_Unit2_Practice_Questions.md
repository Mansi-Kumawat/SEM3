## Answer Key (Selected)

### Section A:
- **A1:** Data represents characteristics of objects/events in coded form (numbers, letters, symbols)
- **A2:** Numeric, Integer, Character, Logical, Complex
- **A3:** Numeric stores decimal values (3.14); Integer stores whole numbers with L suffix (5L)
- **A4:** L suffix (e.g., 5L, 10L)
- **A5:** Qualitative data describes objects using finite discrete classes; cannot be counted/measured
- **A6:** Nominal = no natural order (Gender); Ordinal = has natural order (Education level)
- **A7:** Sequence of data points collected at regular time intervals
- **A8:** Trend, Seasonality, Cyclical, Irregular (TSCI)
- **A9:** Data with many variables/features (dimensions) — each observation has many attributes
- **A10:** sf, sp, leaflet, raster (any 2)

### Section C (Framework):

**Q1:** Definition of data (1) → Data types in R: Numeric, Integer, Character, Logical, Complex with examples (3) → Code examples (1)

**Q2:** Definition of qualitative data (1) → Nominal data — definition + examples (1.5) → Ordinal data — definition + examples (1.5) → Comparison table (1)

**Q3:** Definition of quantitative data (1) → Discrete data — definition + examples (1.5) → Continuous data — definition + examples (1.5) → Comparison (1)

**Q4:** Definition of time series (1) → 4 Components: Trend, Seasonality, Cyclical, Irregular with explanations (3) → Analysis methods: Forecasting, Segmentation, Classification (1)

**Q5:** Definition (1) → Examples: Genomics, Images, Text (1) → Challenges: Curse of dimensionality, computational complexity, visualization difficulty (2) → Solutions: PCA, MDS, Feature Selection (1)

**Q6:** Biological data — definition + types + databases + challenges (1.5) → Spatial data — definition + vector/raster + applications (1.5) → Social network data — definition + nodes/edges + challenges (2)
