## Answer Key (Selected)

### Section A:
- **A1:** Process of converting data into visual environment for easy understanding
- **A2:** Graphical representation of continuous data distribution with adjacent bars
- **A3:** Five-number summary: Min, Q1, Median, Q3, Max
- **A4:** Histogram = continuous, adjacent bars; Bar = categorical, gaps
- **A5:** Plot showing relationship between 2 quantitative variables
- **A6:** Distribution display preserving actual data values
- **A7:** 2D visualization using color for matrix data
- **A8:** Bar chart + cumulative line, based on 80/20 rule
- **A9:** Spatial partition based on distance to seed points
- **A10:** leaflet, ggmap, sf, sp (any 2)
