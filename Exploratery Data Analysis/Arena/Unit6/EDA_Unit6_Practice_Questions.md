## Answer Key (Selected)

### Section A:
- **A1:** Data point that is very different from most of the remaining data
- **A2:** Point (Global), Contextual (Conditional), Collective
- **A3:** "Observation that deviates so much as to arouse suspicion it was generated by a different mechanism"
- **A4:** Value is outlier in specific context — 30°C in winter is outlier, normal in summer
- **A5:** Local Outlier Factor
- **A6:** Fraud detection, healthcare, manufacturing, security, environmental (any 2)
- **A7:** Distance to k-th nearest neighbor — large distance = outlier
- **A8:** Bin width selection — too narrow or too wide causes problems
- **A9:** Statistical analysis of tail of distribution — extreme events
- **A10:** High dimensionality, scalability, varying density, noise vs outlier (any 2)
