## 🔑 Key Definitions

1. **Outlier:** "Data point very different from most remaining data."

2. **Hawkins' Definition:** "Observation that deviates so much as to arouse suspicion it was generated by a different mechanism."

3. **Outlier Score:** "Numeric value quantifying outlierness — real-valued or binary."

4. **Point Outlier:** "Single data point far from rest of data."

5. **Contextual Outlier:** "Value is outlier in specific context but not otherwise."

6. **Collective Outlier:** "Collection of points is outlier, individuals are not."

7. **LOF:** "Compares local density of point with its neighbors — low density = outlier."

## 📊 Key Tables

### Types of Outliers
| Type | Scope | Example | Detection |
|------|-------|---------|-----------|
| **Point** | Single point | Extreme income | Simple threshold |
| **Contextual** | Point + context | 30°C in winter | Context-aware |
| **Collective** | Group/sequence | Irregular ECG | Pattern analysis |

### Detection Methods
| Method | Principle | Advantage | Limitation |
|--------|-----------|-----------|------------|
| **Clustering** | Distance from centroid | Simple, efficient | Assumes spherical |
| **Distance-Based** | K-NN distance | No assumption | Expensive |
| **Density (LOF)** | Local density | Local outliers | Parameter sensitive |
| **Histogram** | Bin frequency | Intuitive | Bin width issue |
| **Extreme Value** | Tail analysis | Theoretical | Univariate focus |
| **Mahalanobis** | Covariance-adjusted | Handles correlations | Assumes normality |
| **Depth-Based** | Data depth measure | No symmetry needed | Ties at convex hull |
| **Probabilistic** | GMM/Bayesian | Probabilistic scores | Model dependent |
| **Subspace** | Feature subsets | High-D outliers | Combinatorial cost |

| Domain | Use Case |

| Manufacturing | Defect identification |
| Security | Intrusion detection |

## 💻 Key R Code

```r
# K-means outlier detection
km <- kmeans(data, centers=3)
distances <- sqrt(rowSums((data - km$centers[km$cluster,])^2))
outliers <- which(distances > quantile(distances, 0.95))

# LOF
library(dbscan)
lof_scores <- lof(data, k=10)
outliers <- which(lof_scores > 1.5)

# Z-score method
z <- (data - mean(data)) / sd(data)
outliers <- which(abs(z) > 3)

# IQR method
Q1 <- quantile(data, 0.25)
Q3 <- quantile(data, 0.75)
IQR_val <- Q3 - Q1
outliers <- which(data < Q1 - 1.5*IQR_val | data > Q3 + 1.5*IQR_val)
```

## ⚠️ Common Mistakes

- ❌ Removing outliers blindly → ✅ Investigate first
- ❌ One method for all → ✅ Choose based on data
- ❌ Ignoring context → ✅ Check contextual outliers
- ❌ Global methods for local outliers → ✅ Use LOF
- ❌ Not using domain knowledge → ✅ Essential!
