## 🔑 KEY DEFINITIONS (RAT LO)

| Term | Definition |
|------|-----------|
| **Structured Data** | Organized, tabular (profiles, metrics) |
| **Unstructured Data** | Raw text/media (posts, comments, videos) |
| **RESTful API** | Request-response model for data access |
| **Stream API** | Real-time continuous data flow |
| **Sentiment Analysis** | Determining emotional tone of text |
| **NER** | Identifying named entities in text |
| **LDA** | Topic modelling algorithm |
| **Web Scraping** | Programmatic data extraction from websites |

---

## 📊 KEY CONCEPTS

| Concept | Details |
|---------|---------|
| **Preprocessing** | Clean → Tokenize → Normalize → Stop words → Stem |
| **Sentiment Approaches** | Lexicon (VADER), ML (Naive Bayes), DL (BERT) |
| **NER Types** | PERSON, ORG, LOCATION, DATE, PRODUCT |
| **Scraping Tools** | BeautifulSoup, Scrapy, Selenium, Puppeteer |
| **Topic Modelling** | LDA — hidden topics in text |
