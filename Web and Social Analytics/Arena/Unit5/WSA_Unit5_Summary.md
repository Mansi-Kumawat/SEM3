## 🔑 KEY DEFINITIONS (RAT LO)

| Term | Definition |
|------|-----------|
| **Influence** | One node's behaviour affects another through network ties over time |
| **Homophily** | Birds of a feather flock together — similar people connect |
| **Confounding** | External factor affects both individuals |
| **Assortativity (r)** | Correlation of node attributes across edges |
| **Homophily Index (H)** | Observed vs expected same-type edges ratio |

---

## ⚖️ THREE SOCIAL FORCES

| Force | Pattern | Timing |
|-------|---------|--------|
| **Influence** | Friends become similar | AFTER connection |
| **Homophily** | Friends are similar | FROM THE START |
| **Confounding** | Same environment | External factor |

---

## 📐 KEY FORMULAS (RAT LO)

| Formula | Expression |
|---------|-----------|
| **Assortativity r** | (1/σ²_q) × Σ[Aij - ki·kj/2m] × xi × xj |
| **r = 1** | Perfect assortative |
| **r = 0** | Random mixing |
| **r = -1** | Perfect disassortative |
| **Homophily H** | (Observed - Expected) / (Total - Expected) |
| **H = 1** | Complete homophily |
| **H = 0** | Random mixing |
| **H < 0** | Heterophily |

---

## 🧪 TESTS TO DISTINGUISH

| Test | Tests For | Method |
|------|-----------|--------|
| **Shuffle Test** | Homophily | Randomize attributes, compare assortativity |
| **Edge Reversal** | Influence | Reverse edges, re-measure influence |
| **Randomisation** | Both | Generate random networks, compare |

| **Induced** | From network structure and preferences |
| **Status** | Similar socioeconomic status |
| **Value** | Similar beliefs and attitudes |
