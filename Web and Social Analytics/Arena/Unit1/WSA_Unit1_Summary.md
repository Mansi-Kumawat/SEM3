## 🔑 KEY DEFINITIONS (RAT LO)

| Term | Definition |
|------|-----------|
| **Social Media** | Web-based technologies for interaction, information sharing & community building |
| **Social Media Analytics (SMA)** | Process of collecting, analyzing, interpreting social media data for actionable insights |
| **Social Media Landscape** | Overall ecosystem of platforms, users, content types & interactions |
| **Web Analytics** | Measurement, collection, analysis & reporting of web data to optimize usage |
| **UGC** | User-Generated Content — content created by users, not by brands/platforms |

1. **B**rand Reputation — sentiment track karo

**Data Collection → Data Processing → Data Analysis → Action**

## 🌐 WEB ANALYTICS — 4 PHASES — Mnemonic: "D-D-K-F"
1. **D**ata Collection — visitor data collect (cookies, logs)
2. **D**ata Processing — clean & organize data
3. **K**PI Development — Key Performance Indicators define karo
4. **F**ormulation — Strategy banao based on insights

## 📐 KEY WEB METRICS & FORMULAS

| Metric | Formula |
|--------|---------|
| **Bounce Rate** | (Single-page sessions / Total sessions) × 100 |
| **Conversion Rate** | (Conversions / Total visitors) × 100 |
| **Pages/Session** | Total page views / Total sessions |
| **Session Duration** | Total time / Total sessions |

---

## ⚖️ WEB ANALYTICS vs SMA

| | Web Analytics | Social Media Analytics |
|--|--------------|----------------------|
| Source | Website | Social platforms |
| Metrics | Page views, bounce rate | Likes, shares, engagement |
| Focus | Website performance | Social engagement |
| Data Type | Structured | Unstructured |
| Tools | Google Analytics | Hootsuite, Brandwatch |
