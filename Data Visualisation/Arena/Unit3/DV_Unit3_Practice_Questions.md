## Answer Key (Selected)

### Section A:
- **A1:** Visualization displaying relationships between multiple categorical variables using vertical axes and flow ribbons — ribbon width = frequency.
- **A2:** Discrete = countable whole numbers (students); Continuous = measured values with decimals (temperature).
- **A3:** Both variables increase together — points rise left to right.
- **A4:** -1 to +1 (negative one to positive one).
- **A5:** Visual representation of correlation matrix — correlation coefficients as color-coded cells.
- **A6:** PCA, t-SNE, UMAP (any three).
- **A7:** Two related measurements on same subject — pairing carries meaning.
- **A8:** Trend, Seasonality, Residual (Noise).
- **A9:** Reduce noise, reveal underlying trend.
- **A10:** Relationship between dose/concentration (X) and response/effect (Y).

### Section C (Framework):
**Q1:** Definition (1) → Structure: axes, segments, ribbons (1.5) → Reading: width interpretation (1) → Advantages + Limitations (1.5)

**Q3:** Definition + why needed (1) → Three methods with comparison table (3) → Applications (1)

**Q5:** Definition (1) → Three components explained (2) → How decomposition helps (1.5) → Design tips (0.5)
