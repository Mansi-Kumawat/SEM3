## 🔑 Key Definitions (RAT LO)

1. **Data Visualization:** "Graphical representation of data using visual elements (charts, graphs, maps) to make data easier to understand, analyze, and communicate."

2. **Visualization Pipeline:** "6-step process: Acquisition → Parsing → Filtering → Mining → Visual Mapping → Rendering"

3. **Image Labelling:** "Assigning metadata tags/annotations to images for ML training and visualization."

4. **Aesthetics:** "Visual properties used to encode data — position, length, angle, area, color, shape, opacity."

5. **Coordinate System:** "Framework defining how data coordinates map to positions on a plot."

6. **Color Scale:** "Mapping between data values and colors — Categorical, Sequential, Diverging."

## 📊 Key Tables

### Visual Variables (Accuracy Ranking)
| Rank | Variable | Accuracy |
|------|----------|----------|
| 1 | Position | Highest |
| 2 | Length | Very High |
| 3 | Angle | High |
| 4 | Area | Medium |
| 5 | Color Hue | Medium-Low |
| 6 | Color Intensity | Low |
| 7 | Shape | Low |
| 8 | Opacity | Lowest |

### Data Types → Charts
| Data Type | Best Chart |
|-----------|-----------|
| Qualitative (Categorical) | Bar, Pie |
| Temporal (Time) | Line, Area |
| Spatial (Location) | Maps (Choropleth, Point) |
| Multivariate | Scatter, Parallel Coords |

### Color Scales
| Type | Use Case | Design |
|------|----------|--------|
| Categorical | No order | Different hues |
| Sequential | Low → High | Light → Dark |
| Diverging | Two extremes | Two hues from center |

### Coordinate Systems
| Type | Axes | Best For |
|------|------|----------|
| Cartesian | x, y perpendicular | Most data |
| Polar | r, θ | Cyclical data |
| Cylindrical | r, θ, z | 3D cylindrical objects |
| Spherical | r, θ, φ | 3D spherical data |
| Geographic | Lat, Long | Maps, GPS |

### Nonlinear Scales (5 Types)
| Type | Use |
|------|-----|
| Logarithmic | Orders of magnitude |
| Exponential | Rapid growth |
| Power | Skewed distributions |
| Square Root | Count data |
| Reciprocal | Inverse relationships |

## ⚠️ Common Mistakes

- ❌ Pie chart for 10+ categories → ✅ Bar chart
- ❌ Log scale without label → ✅ Always write "Log Scale"
- ❌ 10+ colors in one chart → ✅ Max 7±2
- ❌ Cartesian for cyclical data → ✅ Use Polar
- ❌ Same color scale everywhere → ✅ Match scale to data type
