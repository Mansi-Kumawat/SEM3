## Answer Key (Selected)

### Section A:
- **A1:** Graphical representation of data using visual elements (charts, graphs, maps) to make data easier to understand, analyze, and communicate.
- **A2:** Qualitative, Temporal, Spatial, Multivariate
- **A3:** 6-step process: Acquisition → Parsing → Filtering → Mining → Visual Mapping → Rendering
- **A4:** Position (x, y coordinates)
- **A5:** Process of assigning metadata tags/annotations to images for ML training
- **A6:** Categorical, Sequential, Diverging
- **A7:** Two perpendicular axes (x horizontal, y vertical) intersecting at origin (0,0)
- **A8:** 7 ± 2 (i.e., 5 to 9 categories)
- **A9:** LabelImg, CVAT, VGG Image Annotator, Labelbox (any 2)
- **A10:** Line chart / Area chart

### Section C (Framework):
**C1:** Definition (1 mark) → Pipeline diagram (1.5 marks) → Explain each step (2 marks) → User interaction note (0.5 marks)

**C3:** Definition (1 mark) → 4 types with examples (3 marks) → Chart types for each (1 mark)

**C5:** Definition of coordinate system (1 mark) → 3 types (1 mark each = 3 marks) → Use cases and examples (1 mark)
