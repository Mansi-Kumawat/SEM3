## 🔑 Key Definitions (RAT LO)

1. **Bar Plot:** "Uses rectangular bars to compare categorical values — bar length/height encodes the number."

2. **Grouped Bars:** "Display subcategories side-by-side within each main category — for direct comparison."

3. **Stacked Bars:** "Display subcategories stacked on top of each other — for part-to-whole relationships."

4. **Heatmap:** "Represents matrix data with color intensity — rows/columns are categorical, cell color = numerical value."

5. **Histogram:** "Shows numerical data distribution by grouping into equal-width bins — bar height = frequency. NO gaps between bars."

6. **Density Plot:** "Smooth curve showing data distribution — area under curve = 1 (total probability)."

7. **ECDF:** "Shows proportion of observations ≤ each value — step function, no binning needed."

8. **Q-Q Plot:** "Compares sample quantiles vs theoretical quantiles to test distribution fit."

9. **Box Plot:** "Displays five-number summary: Min, Q1, Median, Q3, Max."

10. **Violin Plot:** "Combines box plot + density shape — width shows concentration."

## 📊 Key Comparison Tables

### Grouped vs Stacked Bars
| Feature | Grouped | Stacked |
|---------|---------|---------|
| Goal | Comparison | Composition |
| Compare subcategories? | ✅ Easy | ❌ Hard |
| Shows total? | ❌ No | ✅ Yes |

### Histogram vs Density Plot
| Feature | Histogram | Density |
|---------|-----------|---------|
| Display | Bars + bins | Smooth curve |
| Bin selection | Required | Not needed |
| Overlay multiple | Hard | Easy |

### Box Plot vs Violin Plot
| Feature | Box Plot | Violin |
|---------|----------|--------|
| Outliers | ✅ Shown | ❌ Not clear |
| Distribution shape | ❌ No | ✅ Yes |
| Multimodal | ❌ No | ✅ Yes |

### Proportion Charts
| Categories | Best Chart |
|-----------|-----------|
| 2-3 | Pie |
| 4-5 | Donut |
| 6+ | Stacked bar |
| Compare groups | 100% stacked bar |

## ⚠️ Common Mistakes

- ❌ Bar chart y-axis ≠ 0 → ✅ Always start at ZERO
- ❌ Pie with 10 slices → ✅ Stacked bar
- ❌ Histogram with gaps → ✅ NO gaps (continuous data)
- ❌ Grouped bars for composition → ✅ Stacked bars
- ❌ 3D charts → ✅ 2D (no distortion)
