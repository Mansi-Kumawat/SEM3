## Answer Key (Selected)

### Section A:
- **A1:** Uses rectangular bars to compare categorical values — bar length/height encodes the number.
- **A2:** Grouped = side-by-side for comparison; Stacked = on top for composition/part-to-whole.
- **A3:** Matrix data represented with color intensity — rows/columns = categorical, cell color = numerical value.
- **A4:** Equal-width intervals into which data is grouped (e.g., 0-10, 10-20).
- **A5:** Because histogram represents continuous data — no gaps between intervals.
- **A6:** Empirical Cumulative Distribution Function — shows proportion of observations ≤ each value; step function.
- **A7:** Tests if data follows a specific distribution (usually normal) by comparing quantiles.
- **A8:** Minimum, Q1 (25th), Median (50th), Q3 (75th), Maximum.
- **A9:** Combines box plot + density shape — width shows data concentration.
- **A10:** Donut is cleaner, allows displaying metric in center; use for 4-5 categories.

### Section C (Framework):
**C1:** Definition (1) → Structure: bins, bars, axes (1.5) → Reveals: central tendency, spread, skewness (1.5) → Bin size importance (1)

**C3:** Definition (1) → Structure: axes, points, reference line (1.5) → Interpretation patterns: on-line, curved, S-shape (2) → Use cases (0.5)
