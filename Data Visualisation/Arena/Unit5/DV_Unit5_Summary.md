---

## 🔑 Key Definitions (RAT LO)

1. **Text Data Visualization:** "Turning unstructured text into visual insights that reveal patterns, themes, and sentiment."

2. **Word Cloud:** "Cloud of words where size shows frequency — frequent terms stand out immediately."

3. **Term Co-occurrence Network:** "Terms as nodes, shared appearances as links — reveals relationships and themes."

4. **Word Tree:** "Root word branching into phrases that follow it — shows context and sequences."

5. **Document Similarity Matrix:** "Pairwise similarity scores between documents, shown as heatmaps and clusters."

6. **Data Storytelling:** "Combining data + visuals + narrative to clarify findings, engage audience, prompt decisions."

7. **Overlapping:** "Multiple data elements in same visual space — direct comparison."

8. **Linear Axis:** "Equal distance = equal difference (standard scale)."

9. **Logarithmic Axis:** "Equal distance = equal ratio (multiplicative change)."

10. **Direct Area Visualization:** "Area shows magnitude and parts of a whole."

## 📊 Key Comparison Tables

### Word Cloud vs Frequency Chart
| Feature | Word Cloud | Frequency Chart |
|---------|-----------|-----------------|
| Speed | Fast overview | Slower |
| Precision | Imprecise | Exact counts |
| Best for | Presentations | Analysis |

### Similarity Metrics
| Metric | Formula | Range |
|--------|---------|-------|
| Cosine | Angle between vectors | 0 to 1 |
| Jaccard | Set overlap | 0 to 1 |
| Euclidean | Distance | 0 to ∞ |

### Linear vs Log Axes
| Feature | Linear | Log |
|---------|--------|-----|
| Equal distance = | Equal difference | Equal ratio |
| Example | 0, 10, 20, 30 | 1, 10, 100, 1000 |
| Best for | Absolute values | Wide ranges |

### Text Preprocessing Steps
| Step | Action |
|------|--------|
| 1. Collect | Gather text |
| 2. Clean | Remove noise, stop words |
| 3. Tokenise | Split into words |
| 4. Normalise | Lowercase, stemming |
| 5. Count | Calculate frequencies |
| 6. Visualise | Create visuals |

## ⚠️ Common Mistakes

- ❌ Word cloud without preprocessing → ✅ Remove stop words first
- ❌ Comparing cloud sizes precisely → ✅ Use frequency chart
- ❌ Wrong similarity metric → ✅ Choose based on data type
- ❌ >10 story points → ✅ Keep ≤10 for focus
- ❌ Linear for exponential → ✅ Use log scale
- ❌ Not labeling log axes → ✅ Write "Log Scale"
- ❌ Radius proportional → ✅ Area proportional to value
- ❌ Pie with 15 slices → ✅ Use treemap
