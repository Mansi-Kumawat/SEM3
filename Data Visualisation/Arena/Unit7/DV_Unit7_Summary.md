## Module 7: Best Practices in Data Visualization

---

## 🔑 Key Concepts (RAT LO)

1. **Multi-Panel Figures:** "Two or more related visualisations in single figure — common purpose, every panel contributes to same story."

2. **Data-to-Ink Ratio (Tufte):** "Maximize data ink, minimize chartjunk — every element should serve a purpose."

3. **Title Types:**
   - Descriptive: "Sales by Region"
   - Informative: "Sales Increased 20% in Q4"
   - Action-oriented: "Increase Marketing Budget"

4. **Audience Types:**
   - Technical: Can handle complexity
   - Non-technical: Need simple, clear
   - Decision-makers: Need actionable insights

---

## 📊 Key Tables

### Multi-Panel Layouts
| Layout | Best For |
|--------|----------|
| Side-by-side | Direct comparison |
| Vertical stacked | Sequential information |
| Grid | Many related visualizations |

### Chart Selection by Variables
| Variables | Chart Options |
|-----------|--------------|
| 1 categorical | Bar, pie |
| 1 numerical | Histogram, box plot |
| 2 numerical | Scatter, line |
| 3+ | Bubble, heatmap, dashboard |

### Common Mistakes
| Mistake | Problem |
|---------|---------|
| Truncated Y-axis | Exaggerates differences |
| 3D effects | Distorts perception |
| Too many colors | Confusing |
| Missing labels | Unclear meaning |
