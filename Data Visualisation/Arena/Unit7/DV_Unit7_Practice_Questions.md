## Answer Key (Selected)

### Section A:
- **A1:** Two or more related visualisations arranged in single figure — common purpose/theme, every panel contributes to same story.
- **A2:** Side-by-side (horizontal), Vertical stacked, Grid
- **A3:** Maximize data ink, minimize chartjunk — every element should serve a purpose.
- **A4:** Descriptive, Informative, Action-oriented
- **A5:** Tell what axes represent, provide units/scale, ensure correct interpretation
- **A6:** Minimum 12pt
- **A7:** Data types, number of variables, analytical objective (any three)
- **A8:** Complex visualizations, statistical charts, detailed information
- **A9:** Decorative elements that don't convey information
- **A10:** Exaggerates small differences, misleading

**Q1:** Definition (1) → Three layouts with description (2) → Best use cases (1) → Design practices (1)

**Q3:** Definition (1) → How to balance (1.5) → What to remove (1) → Context tools (1.5)

**Q5:** Data types (1) → Variables (1) → Objectives (1.5) → Audience (1.5)
