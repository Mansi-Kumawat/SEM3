## Answer Key (Selected)

### Section A:
- **A1:** Several outputs measured at the same time — studied together to understand system behavior.
- **A2:** Upward (rising), Downward (falling), Stable (constant)
- **A3:** α (0 to 1) — controls responsiveness. α→1 = more responsive, α→0 = smoother.
- **A4:** Vector = points/lines/polygons (discrete); Raster = grid/pixels (continuous surfaces)
- **A5:** Cylindrical, Conic, Azimuthal
- **A6:** Map that shades regions by statistical value — darker = higher
- **A7:** Map where regions resized by statistic, not physical area
- **A8:** Simple point, Dot density, Event map
- **A9:** Area (not radius)
- **A10:** Marker clustering, Heat maps, Density-based hotspots (DBSCAN)

### Section C (Framework):
**Q1:** Definition (1) → Components (1) → Three classification methods with comparison (2) → Design: normalization, color (1)

**Q3:** Definition (1) → Two types comparison table (2) → Design: area ∝ value, legend, overlapping (1.5) → Applications (0.5)

**Q4:** Definition (1) → Three methods with formulas (2) → Characteristics comparison (1) → Choosing α (1)
